# Seed Idea — Workflow Automation Tool

Build a workflow automation tool for real estate teams.

---

This is the raw idea. It is deliberately loose and under-specified.
Do not pre-scope it before handing it to Prometheus. Prometheus should compare
credible approaches, select a bounded implementation, and publish a complete
registered schema-v1 generated-agent package. It must stop before implementation
and give the restart plus new-conversation handoff to the generated agent.
